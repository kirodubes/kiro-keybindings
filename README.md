# kiro-keybindings

A slick **PySide6 + QML** keybindings cheatsheet for Kiro. It auto-detects the running
tiling window manager, finds that environment's `~/.config/<wm>/keybindings.txt`, and shows
it as a searchable, color-coded overlay — the same look and the same hotkey on every Kiro desktop.

## Run

```sh
kiro-keybindings              # auto-detect the running WM
kiro-keybindings --file ~/.config/ohmychadwm/keybindings.txt   # explicit file
```

## How it works

- **Data:** the per-WM `keybindings.txt` files (generated by `/kiro-create-keybindings`) — one
  identical format across all TWMs. This app is purely the presentation layer.
- **Detection:** `pgrep -x` against known WM names, with `$XDG_CURRENT_DESKTOP` fallback.
- **UI:** frameless dark window, Kiro blue→green gradient, color-coded keycap chips
  (Super/Ctrl/Shift/Alt), live type-to-filter search. `Esc` closes.

## Dependencies

`pyside6`, `shiboken6` — everything else (qt6-base, qt6-declarative, qt6-svg, python) already ships on Kiro.
